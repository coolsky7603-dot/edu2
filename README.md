# 국방예산 인사이트 대시보드

`index.html`을 브라우저에서 열면 실행됩니다. 설치나 인터넷 연결이 필요하지 않습니다.

- 부문 및 회계구분 필터, 프로그램 검색, 초기화
- 4개 요약 지표와 8개 그래프
- 상세 내역 정렬 및 필터 결과 CSV 다운로드
- 데스크톱·태블릿·모바일 화면 지원

## 데이터와 계산

`프로그램별_재원.xlsx`의 32개 항목을 `data.js`에 담은 스냅샷입니다. 원본 엑셀 수정 사항이 자동 반영되지는 않습니다.

금액 단위는 억 원입니다. 증감 = 2027년 − 2026년, 증감률 = 증감 ÷ 2026년입니다. 2026년 값이 0인 경우 증감률은 표시하지 않습니다. 내부거래·보전지출 및 내부거래는 음수로 합산됩니다. 원형·면적 구성비와 프로그램 순위는 양수 금액만 표시합니다. 산점도는 두 연도 모두 양수인 프로그램을 표시합니다.

전체 항목 합계는 2026년 677,039억 원, 2027년 732,776억 원입니다. 원문 총재원보다 연도별 1억 원씩 작으며, 원문 프로그램 표의 억 원 단위 반올림 차이를 보정하지 않고 그대로 반영했습니다. 계산한 증감률도 원문 증감률과 반올림 차이가 날 수 있습니다.

차감액은 별도 프로그램명이 없으므로 그래프·상세 화면에서는 회계구분명을 항목명으로 표시합니다.

## 파일

- `index.html`: 화면 구조
- `styles.css`: 반응형 스타일
- `app.js`: 필터, 그래프, 계산, 정렬, CSV
- `data.js`: 엑셀에서 추출한 데이터

외부 라이브러리, CDN, 네트워크 요청을 사용하지 않습니다.
